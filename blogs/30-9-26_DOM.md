# The Complete Guide to the Document Object Model (DOM) in JavaScript

The **Document Object Model (DOM)** is a programming interface for web documents. It represents the page as a hierarchical tree of nodes and objects, allowing programming languages like JavaScript to dynamically read, modify, add, and delete HTML elements, attributes, and styles.

## 1. Understanding the DOM Architecture

When a browser loads an HTML document, it parses the markup and builds the DOM tree:

- **`window`**: The global browser window and root object.
- **`document`**: The entry point to the web page inside `window`.
- **Node Hierarchy**:
  - **`DocumentNode`**: Represents the root document.
  - **`ElementNode`**: Corresponds to HTML tags (e.g., `<div>`, `<p>`).
  - **`TextNode`**: The actual text content inside tags.
  - **`CommentNode`**: HTML comments (`<!-- comment -->`).

```
                window
                  │
               document
                  │
               <html>
              /      \
          <head>    <body>
          /    \     /    \
       <title> <meta> <h1>  <p>
```

## 2. Selecting DOM Elements

Modern JavaScript provides both modern query selector methods and legacy collection selectors.

### A. Modern Selectors (Recommended)

- **`document.querySelector(cssSelector)`**: Returns the **first** matching element, or `null`.
- **`document.querySelectorAll(cssSelector)`**: Returns a static (non-live) `NodeList` containing all matches.

```javascript
// Single element selection
const mainHeader = document.querySelector("#main-title");
const activeCard = document.querySelector(".card.active");
const firstSubmitBtn = document.querySelector("button[type='submit']");

// Multiple element selection
const navLinks = document.querySelectorAll(".nav-menu a");

// Iterating over a NodeList
navLinks.forEach((link) => {
    console.log(link.href);
});

// Converting a NodeList to a standard Array:
const linksArray = Array.from(navLinks);
```

### B. Legacy Selectors

These return single elements, live `HTMLCollection`s, or live `NodeList`s:

| Method | Returns | Type |
|---|---|---|
| `document.getElementById('id')` | Single Element | `Element` |
| `document.getElementsByClassName('class')` | All matching elements | Live `HTMLCollection` |
| `document.getElementsByTagName('tag')` | All matching tags | Live `HTMLCollection` |
| `document.getElementsByName('name')` | Form elements with `name` attribute | Live `NodeList` |

```javascript
const banner = document.getElementById("banner");
const items = document.getElementsByClassName("list-item"); // Live collection!
```

> ⚠️ **Key Difference:** A **live collection** updates automatically in memory if elements are added or removed from the DOM; a **static NodeList** (from `querySelectorAll`) remains a snapshot of the DOM at the time of the query.

## 3. Traversing the DOM Tree

Instead of re-querying the whole document, you can navigate relative to an existing element.

### Element Traversal vs. Node Traversal
Always prefer **Element traversal properties** unless you explicitly need whitespace and comments (`TextNode` / `CommentNode`).

| Direction | Element-Only (ignores text/comments) | All Nodes (includes text & comments) |
|---|---|---|
| **Parent** | `element.parentElement` | `node.parentNode` |
| **Children** | `element.children` | `node.childNodes` |
| **First Child** | `element.firstElementChild` | `node.firstChild` |
| **Last Child** | `element.lastElementChild` | `node.lastChild` |
| **Next Sibling** | `element.nextElementSibling` | `node.nextSibling` |
| **Previous Sibling** | `element.previousElementSibling` | `node.previousSibling` |

### Ascendant Lookup with `.closest()`
Finds the closest ancestor matching a CSS selector:

```javascript
const deleteButton = document.querySelector(".btn-delete");
// Walks upward to find the parent table row:
const tableRow = deleteButton.closest("tr");
```

## 4. Creating, Inserting, and Removing Elements

### A. Creating Elements
```javascript
const newCard = document.createElement("div");
newCard.classList.add("card");
```

### B. Modern Insertion Methods (`append`, `prepend`, `before`, `after`)
```javascript
const container = document.querySelector("#container");
const child = document.createElement("p");
child.textContent = "Hello World";

container.append(child);         // Adds to the end of container (accepts text & elements)
container.prepend(child);        // Adds to the start of container
container.before(child);         // Inserts before container as a sibling
container.after(child);          // Inserts after container as a sibling
```

### C. Precision Insertion with `.insertAdjacentHTML()`
Inserts HTML strings directly into designated positions without re-parsing existing DOM:

```javascript
// Positions: 'beforebegin', 'afterbegin', 'beforeend', 'afterend'
container.insertAdjacentHTML("beforeend", `<p class="highlight">Appended item</p>`);
```

### D. Removing Elements
```javascript
const elementToRemove = document.querySelector(".modal");

// Modern way (direct removal)
elementToRemove.remove();

// Legacy way (via parent)
// elementToRemove.parentNode.removeChild(elementToRemove);
```

### E. Cloning and Replacing
```javascript
// Clone (pass true for deep clone including children)
const cardCopy = newCard.cloneNode(true);

// Replace an existing child
container.replaceChild(newCard, oldCard);
```

## 5. Manipulating Content and HTML

There are three primary ways to inspect and modify an element's text or HTML:

```javascript
const box = document.querySelector("#box");
```

| Property | Behavior | Security Risk |
|---|---|---|
| `textContent` | Returns all raw text content including hidden text. Strips markup on assignment. | 🟢 Safe from XSS |
| `innerText` | Returns rendered, visible text (takes CSS styling into account; triggers reflow). | 🟢 Safe from XSS |
| `innerHTML` | Reads or parses raw HTML markup within the element. | 🔴 Prone to Cross-Site Scripting (XSS) |

```javascript
// Safe plain text insertion:
box.textContent = "Welcome back, Jai!";

// HTML string insertion (only use with trusted/sanitized data):
box.innerHTML = "<strong>Status:</strong> Active";
```

## 6. Manipulating Attributes and Custom Data

### A. Standard Attributes
```javascript
const img = document.querySelector("img");

img.setAttribute("src", "avatar.png");
console.log(img.getAttribute("src")); // "avatar.png"
console.log(img.hasAttribute("alt"));  // false
img.removeAttribute("alt");

// Common direct property access:
img.id = "user-avatar";
img.src = "new-avatar.png";
```

### B. Custom Data Attributes (`data-*`)
HTML elements support custom `data-*` attributes, accessed via the `dataset` property:

```html
<button id="cart-btn" data-product-id="402" data-category="electronics">Add</button>
```

```javascript
const btn = document.querySelector("#cart-btn");

// Read values:
console.log(btn.dataset.productId); // "402" (kebab-case converts to camelCase)
console.log(btn.dataset.category);  // "electronics"

// Write/update values:
btn.dataset.discount = "15"; // Sets data-discount="15"
```

## 7. Manipulating Classes and Inline Styles

### A. The `classList` API (Recommended for Styling)
Never write raw `className = "..."` strings if you can avoid it; use `classList`:

```javascript
const modal = document.querySelector(".modal");

modal.classList.add("open", "visible"); // Add class(es)
modal.classList.remove("hidden");       // Remove class(es)
modal.classList.toggle("dark-mode");    // Add if missing, remove if present
const isOpen = modal.classList.contains("open"); // Check if present (returns boolean)
modal.classList.replace("old-theme", "new-theme");
```

### B. Direct Inline Styles (`style` Property)
Styles set this way apply as inline CSS (`style="..."`). CSS property names use **camelCase**:

```javascript
const box = document.querySelector(".box");

box.style.backgroundColor = "#1e293b";
box.style.fontSize = "18px";
box.style.display = "flex";

// Resetting an inline style:
box.style.display = "";
```

### C. Reading Computed Styles
To inspect an element's actual calculated CSS (including styles from stylesheets):

```javascript
const computed = window.getComputedStyle(box);
console.log(computed.getPropertyValue("background-color"));
console.log(computed.margin);
```

## 8. Event Handling and the Event Lifecycle

### A. Adding & Removing Event Listeners
```javascript
const btn = document.querySelector("#save-btn");

function handleSave(event) {
    console.log("Saved!", event);
}

// Attach listener
btn.addEventListener("click", handleSave);

// Remove listener (requires reference to the same named function)
btn.removeEventListener("click", handleSave);
```

### B. The Event Object (`event`)
```javascript
btn.addEventListener("click", (e) => {
    console.log(e.type);          // "click"
    console.log(e.target);        // The actual element that fired the event
    console.log(e.currentTarget); // The element to which the listener is attached
});
```

### C. Event Propagation: Capturing & Bubbling
Events travel in three distinct phases:

1. **Capturing Phase**: Travels down from `window` through ancestors to the target.
2. **Target Phase**: Reaches the intended target element.
3. **Bubbling Phase**: Bubbles back up from the target through ancestors to `window`.

```javascript
// Controlling propagation:
child.addEventListener("click", (e) => {
    e.stopPropagation(); // Prevents event from bubbling up to parent handlers
});

form.addEventListener("submit", (e) => {
    e.preventDefault();  // Cancels default browser behavior (e.g. page reload)
});
```

### D. Event Delegation Pattern
Instead of attaching individual listeners to dozens of child elements, attach **one single listener** to the parent and inspect `e.target`:

```javascript
const list = document.querySelector("#todo-list");

list.addEventListener("click", (e) => {
    // Check if clicked element is a delete button
    if (e.target.matches(".btn-delete")) {
        const item = e.target.closest("li");
        item.remove();
    }
});
```

## 9. Forms and Input Handling

### Common Form Events:
- `submit`: Fires when a `<form>` is submitted.
- `input`: Fires synchronously whenever a value changes in `<input>`, `<textarea>`, or `<select>`.
- `change`: Fires when an input loses focus after changing, or when a dropdown selection is finalized.
- `focus` / `blur`: Fired when an element receives or loses focus (does not bubble; use `focusin`/`focusout` for delegation).

```javascript
const form = document.querySelector("#signup-form");

form.addEventListener("submit", (e) => {
    e.preventDefault(); // Stop default full page refresh

    // Convenient FormData extraction:
    const formData = new FormData(form);
    const email = formData.get("email");
    const password = formData.get("password");

    console.log({ email, password });
});
```

## 10. DOM Performance Optimization

DOM manipulation is one of the most resource-intensive operations in the browser. Modifying dimensions, geometry, or layout forces the browser to recalculate layouts (**Reflow**) and redraw pixels (**Repaint**).

### 1. Use `DocumentFragment` for Batch DOM Operations
Avoid inserting items one-by-one inside a loop:

```javascript
// ❌ SLOW: Causes 1,000 reflows and repaints
for (let i = 0; i < 1000; i++) {
    const li = document.createElement("li");
    li.textContent = `Item ${i}`;
    list.appendChild(li);
}

//  OPTIMAL: Uses DocumentFragment (only 1 reflow)
const fragment = document.createDocumentFragment();
for (let i = 0; i < 1000; i++) {
    const li = document.createElement("li");
    li.textContent = `Item ${i}`;
    fragment.appendChild(li); // Appends in memory
}
list.appendChild(fragment);   // Appended to real DOM once
```

### 2. Page Loading Events: `DOMContentLoaded` vs. `load`
```javascript
// Fires when HTML is fully parsed and DOM is ready (does not wait for images/stylesheets)
document.addEventListener("DOMContentLoaded", () => {
    console.log("DOM tree is completely built.");
});

// Fires when everything (including images, stylesheets, and iframes) is loaded
window.addEventListener("load", () => {
    console.log("All external assets finished loading.");
});
```

## 11. Summary Cheat Sheet

| Task | Modern Recommended Method |
|---|---|
| **Select 1 element** | `document.querySelector(".class")` |
| **Select multiple elements** | `document.querySelectorAll("selector")` |
| **Create element** | `document.createElement("tagName")` |
| **Insert element** | `parent.append(child)` or `parent.insertAdjacentHTML(...)` |
| **Remove element** | `element.remove()` |
| **Manage classes** | `element.classList.add()`, `.remove()`, `.toggle()` |
| **Read/Write text** | `element.textContent` |
| **Set attributes** | `element.setAttribute("attr", "val")` or direct property |
| **Listen to events** | `element.addEventListener("type", handler)` |
| **Stop default action** | `event.preventDefault()` |
| **Stop event propagation** | `event.stopPropagation()` |
| **Batch DOM additions** | `document.createDocumentFragment()` |
