# JavaScript Fetch API: Complete Reference & Guide

The **Fetch API** provides a modern, promise-based interface for fetching resources (including across the network) asynchronously in web browsers and modern Node.js environments.

## 1. Core Concepts

- **Promise-based**: Returns a `Promise` that resolves to the `Response` object representing the response to the request.
- **HTTP Errors Don't Reject**: A `fetch()` promise only rejects on **network failure** or if anything prevented the request from completing (e.g., DNS error, offline). It **does not** reject on HTTP errors like `404` or `500`.
- **Stream-based**: Reading response bodies (e.g., via `.json()` or `.text()`) consumes the stream and can only be done once.

## 2. Basic Syntax

```javascript
fetch(url, [options])
  .then(response => {
    // Handle response metadata
    return response.json(); // parses JSON response into native JavaScript objects
  })
  .then(data => {
    // Work with the parsed data
    console.log(data);
  })
  .catch(error => {
    // Network or parsing errors
    console.error('Fetch error:', error);
  });
```

Using modern `async/await`:

```javascript
async function loadData(url) {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new Error(`HTTP error! Status: ${response.status}`);
    }
    const data = await response.json();
    return data;
  } catch (error) {
    console.error('Failed to fetch:', error);
  }
}
```

## 3. Making a GET Request

By default, `fetch()` performs a `GET` request.

```javascript
async function fetchUsers() {
  try {
    const response = await fetch('https://jsonplaceholder.typicode.com/users');
    
    if (!response.ok) {
      throw new Error(`HTTP error! Status: ${response.status}`);
    }

    const users = await response.json();
    console.log('Users list:', users);
  } catch (error) {
    console.error('Error fetching users:', error);
  }
}

fetchUsers();
```

## 4. Making a POST Request

To send data to a server, set `method: 'POST'`, provide a `body` (typically serialized using `JSON.stringify()`), and specify the `Content-Type` header.

```javascript
async function createUser(userData) {
  try {
    const response = await fetch('https://jsonplaceholder.typicode.com/users', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify(userData),
    });

    if (!response.ok) {
      throw new Error(`Failed to create user. Status: ${response.status}`);
    }

    const createdUser = await response.json();
    console.log('User created:', createdUser);
    return createdUser;
  } catch (error) {
    console.error('Error:', error);
  }
}

// Example invocation
createUser({
  name: 'Jane Doe',
  email: 'jane@example.com'
});
```

## 5. PUT, PATCH, and DELETE Requests

### PUT (Full Update)
```javascript
async function updateUser(id, updatedData) {
  const response = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`, {
    method: 'PUT',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(updatedData)
  });
  return response.json();
}
```

### PATCH (Partial Update)
```javascript
async function patchUserEmail(id, newEmail) {
  const response = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`, {
    method: 'PATCH',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email: newEmail })
  });
  return response.json();
}
```

### DELETE
```javascript
async function deleteUser(id) {
  const response = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`, {
    method: 'DELETE'
  });

  if (!response.ok) {
    throw new Error(`Could not delete item: ${response.status}`);
  }
  return response.ok;
}
```

## 6. Proper Error Handling

Because `fetch()` does not throw on standard HTTP errors (`4xx`, `5xx`), always check `response.ok`:

```javascript
async function fetchResourceSafely(url) {
  try {
    const response = await fetch(url);

    // Check if the response status is in the 200–299 range
    if (!response.ok) {
      // Extract error details if server provides a JSON error payload
      const errorPayload = await response.json().catch(() => null);
      throw new Error(
        errorPayload?.message || `Request failed with status ${response.status}`
      );
    }

    return await response.json();
  } catch (error) {
    // Handles network errors, DNS failures, or manually thrown errors above
    console.error('Fetch operation failed:', error.message);
    throw error;
  }
}
```

## 7. Setting Headers & Authentication

### Bearer Token Authentication
```javascript
async function getProtectedResource(token) {
  const response = await fetch('https://api.example.com/protected', {
    method: 'GET',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Accept': 'application/json'
    }
  });
  return response.json();
}
```

### Credentials & Cookies
To send cookies with cross-origin requests:
```javascript
fetch('https://api.example.com/profile', {
  credentials: 'include' // Options: 'omit', 'same-origin', 'include'
});
```

## 8. Handling Different Response Types

`Response` exposes several asynchronous parsers depending on what the server returns:

| Method | Description | Common Use Case |
| :--- | :--- | :--- |
| `response.json()` | Parses body as JSON object | REST APIs returning JSON |
| `response.text()` | Parses body as raw UTF-8 string | HTML, plain text, XML |
| `response.blob()` | Returns a binary Blob | Images, PDFs, downloaded files |
| `response.formData()` | Parses as `FormData` | Multipart form responses |
| `response.arrayBuffer()` | Low-level binary buffer | Audio, binary buffers, WebAssembly |

### Example: Downloading an Image as a Blob
```javascript
async function displayImage(url, imgElement) {
  const response = await fetch(url);
  const blob = await response.blob();
  imgElement.src = URL.createObjectURL(blob);
}
```

## 9. Canceling Requests with AbortController

Use `AbortController` to cancel long-running requests or set custom timeouts.

### Adding a Request Timeout
```javascript
async function fetchWithTimeout(url, timeoutMs = 5000) {
  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), timeoutMs);

  try {
    const response = await fetch(url, { signal: controller.signal });
    return await response.json();
  } catch (error) {
    if (error.name === 'AbortError') {
      throw new Error(`Request timed out after ${timeoutMs}ms`);
    }
    throw error;
  } finally {
    clearTimeout(timeoutId);
  }
}
```

## 10. Reusable Fetch Wrapper Utility

A lightweight wrapper to handle JSON payloads, headers, and status checks automatically:

```javascript
class ApiClient {
  constructor(baseUrl = '', defaultHeaders = {}) {
    this.baseUrl = baseUrl;
    this.defaultHeaders = defaultHeaders;
  }

  async request(endpoint, options = {}) {
    const url = `${this.baseUrl}${endpoint}`;
    const headers = {
      'Content-Type': 'application/json',
      ...this.defaultHeaders,
      ...options.headers,
    };

    const config = {
      ...options,
      headers,
    };

    if (config.body && typeof config.body === 'object') {
      config.body = JSON.stringify(config.body);
    }

    const response = await fetch(url, config);

    if (!response.ok) {
      const errorData = await response.json().catch(() => null);
      const error = new Error(`HTTP ${response.status}: ${response.statusText}`);
      error.status = response.status;
      error.data = errorData;
      throw error;
    }

    // Return empty for 204 No Content
    if (response.status === 204) return null;

    return response.json();
  }

  get(endpoint, options) {
    return this.request(endpoint, { ...options, method: 'GET' });
  }

  post(endpoint, body, options) {
    return this.request(endpoint, { ...options, method: 'POST', body });
  }

  put(endpoint, body, options) {
    return this.request(endpoint, { ...options, method: 'PUT', body });
  }

  delete(endpoint, options) {
    return this.request(endpoint, { ...options, method: 'DELETE' });
  }
}
```
