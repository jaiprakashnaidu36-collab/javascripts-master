# Understanding Scope in JavaScript: Global, Block, and Function Scope

Scope in JavaScript determines where variables, functions, and objects are accessible in your code. Understanding how scope works is crucial to writing clean code and avoiding unexpected bugs.

---

## 1. What is Scope?

Think of scope as the "visibility" boundary of your variables:
* **Global Scope:** Variables declared outside of any block or function can be accessed anywhere in the script.
* **Local / Block Scope:** Variables declared inside curly braces `{ ... }` are generally only accessible within that specific block.

---

## 2. Global Scope

When a variable is declared at the top level of your script, outside of any functions or blocks, it lives in the global scope:

```javascript
let x = 10; // Global variable

console.log("Global variable:", x); // Output: Global variable: 10
```

`x` is available throughout the program.

---

## 3. Block Scope: `let` and `const` vs. `var`

A block is delimited by curly braces `{ ... }`. How a variable behaves inside a block depends on the keyword used to declare it:

```javascript
{
    let a = 20;   // Block-scoped
    const b = 30; // Block-scoped
    var c = 40;   // Function-scoped (leaks out of standalone blocks)
}

// Accessing let and const outside the block:
// console.log("Variable declared using let:", a);   // ReferenceError: a is not defined
// console.log("Variable declared using const:", b); // ReferenceError: b is not defined

// Accessing var outside the block:
console.log("Variable declared using var:", c);     // Output: Variable declared using var: 40
```

### Key Differences:
* **`let` & `const`:** Introduced in ES6, these are strictly **block-scoped**. Attempting to read them outside the curly braces where they were defined results in a `ReferenceError`.
* **`var`:** Does **not** respect regular block boundaries. It is **function-scoped**, meaning it leaks outside of simple blocks (`if`, `for`, or standalone `{}`) into the enclosing function or global scope.

---

## 4. Function Scope and Nested Functions

Functions create their own scope boundary. Both variables and inner functions declared within an outer function are local to that function.

```javascript
function row(us_nm) {
    console.log("Outer parameter:", us_nm);

    // col is local to row
    function col(nm) {
        console.log("Function inside a function:", nm);
    }

    col(19); // Accessible inside row
}

row("jai");
// Output:
// Outer parameter: jai
// Function inside a function: 19

// col(10); // ReferenceError: col is not defined (cannot be accessed outside row)
```

In this example:
* The inner function `col` is scoped locally to `row`.
* Calling `col` outside of `row` throws an error because it does not exist in the outer scope.

---

## Summary Cheat Sheet

| Keyword | Scope Type | Can Leak Out of `{ ... }` Blocks? | Recommended Usage |
| :--- | :--- | :--- | :--- |
| `let` | Block Scope | ❌ No | When the value needs to change |
| `const` | Block Scope | ❌ No | Default choice for fixed values |
| `var` | Function Scope |  Yes (only contained by functions) | Legacy; avoid in modern JavaScript |
